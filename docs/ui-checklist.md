# 管理页手动验收清单（AC-UI-001 ~ 018）

> UI 自动化成本高，原型采用「后端 API 测试 + 静态检查 + 手动清单」组合（`specs/modules/admin-ui.md` §8）。
> 每次 UI 改动或彩排，按本清单逐条勾选；未勾选项不得在答辩中声称已支持。
> 静态部分由 `tests/unit/test_AC_UI_012_014_usability.py`、`test_AC_UI_015_018_layout.py`、`test_AC_UI_010_ui_static_checks.py` 与 `tests/integration/test_AC_UI_001_admin_static.py` 兜底；观感与真实交互仍需人工走查。

## 0. 启动环境

```bash
python scripts/seed.py
```

```bash
python -m uvicorn app.main:app --reload
```

- 打开 `http://127.0.0.1:8000/admin/`（若 8000 被占用，改用 `--port 8010` 等端口并打开对应地址）。
- 浏览器控制台除演示模式探测外无 JS 报错；Network 面板中除 `localhost` 外无外部请求。
- 顶部填入 `ADMIN_TOKEN`（本地演示默认 `dev-admin-token`）与操作人，点「进入控制台」。

自动化部分：

```bash
python -m pytest -q tests/unit/test_AC_UI_010_ui_static_checks.py tests/unit/test_AC_UI_012_014_usability.py tests/unit/test_AC_UI_015_018_layout.py tests/integration/test_AC_UI_001_admin_static.py
```

## 1. 全局检查

- [ ] **AC-UI-013**：六页都能看到「本页要做什么」与「下一步」；左下角「演示向导」显示 8 步与完成状态；导入、筛选、审核、创建任务、启动、模拟退订后，页面就地出现下一步提示。

## 8. 10 分钟演示（AC-UI-011）

按 `docs/demo-script.md` 从重置开始：

1. 导入 → 筛选 → 审核 1 条；
2. 建任务（最低分 70）→ 预览 → 启动 → **约 10 秒后暂停**；
3. 合规 → 模拟 `+15555559004` 退订；
4. 回任务详情 → 恢复 → 等待完成；
5. 检查最终统计：**成功率 4 / 失败 3 / 跳过 13，成功率 57.1%**；
6. 明细过滤与「日志」→ 记录页；
7. 审计查询 + 哈希链校验 → 配置页说明。

> 重试次数以实际为准：演示脚本记录的 4 次依赖暂停时机，常见为 2–4 次；其余数字应稳定。

## 9. 已知限制

- 管理页不做登录 / 权限体系；口令是共享访问令牌，仅存 `sessionStorage`。
- `/pool` 没有搜索参数，用户池搜索是客户端在当前加载页内过滤（最多加载 100 条）。
- 评分分布由前 100 条线索客户端聚合；演示数据 44 条不受影响。
- 演示沙盒始终显示；服务端 `DEMO_MODE=false` 时点击动作会提示未启用。
- 状态色只表达语义；完整号码、token、消息正文不出现在界面。
