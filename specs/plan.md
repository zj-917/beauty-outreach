# plan：技术方案、排期、风险与演示方案

> 版本 v1.0 · 状态 定稿（2026-11-13 冻结） · 今天 = 2026-11-13（周五）；截止 = 2026-11-16（周一）18:00，之后腾讯会议演示。

## 1. 技术方案摘要

| 项 | 选择 |
|---|---|
| 语言 / 框架 | Python 3.11+ · FastAPI · Pydantic v2 · SQLAlchemy 2.x · SQLite(WAL) |
| 加密 / 哈希 | `cryptography`（Fernet）+ 标准库 `hmac` |
| 前端 | 原生 HTML + JS（无构建），FastAPI `StaticFiles` 提供 |
| 测试 | pytest + httpx(`TestClient`) + 自研 `FakeClock`；ruff |
| 外部平台 | Provider 接口 + Mock 实现；真实实现仅 Stub |
| 任务执行 | 进程内单 Worker 线程 + DB 作队列 + 租约 |
| 运行方式 | `uvicorn app.main:app`；`scripts/seed.py`、`scripts/demo.py` |

详见 `02-architecture.md`。

**答辩预案（高概率提问）**：为什么用 Mock？—— 官方接口不支持、且题目禁止爬虫；如何保证不重复发送？—— 幂等键 + 唯一约束 + 同键重发 + 跨任务防重；退订怎么保证即时生效？—— 闸门实时查库，不缓存；崩溃后会不会双发？—— 租约回收 + 同键重发 + Provider 幂等；如何上生产？—— §12。
